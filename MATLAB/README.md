# MATLAB

Introductory MATLAB projects developed to build computational skills relevant to quantitative research and clinical neuropsychology.

## Projects

### 01 - Reaction Time Data Analysis

A small educational project using simulated reaction-time data to demonstrate:

- Creating and working with numerical arrays
- Descriptive statistics
- Identifying unusually slow responses
- Data visualization
- Comparing experimental conditions

**Status:** Introductory project

> This project uses simulated data for educational purposes and does not represent analysis of real clinical or experimental data.

## Skills demonstrated

- MATLAB syntax
- Arrays
- Basic statistical calculations
- Conditional logic
- Visualization

More projects will be added as MATLAB skills develop.
