# Reaction Time Data Analysis

## Overview

This introductory MATLAB project demonstrates basic analysis and visualization of simulated reaction-time data from two hypothetical cognitive-task conditions.

The project was created as a computational learning exercise to develop MATLAB skills relevant to quantitative research and clinical neuropsychology.

## Objective

To demonstrate how MATLAB can be used to:

- Organize numerical data
- Calculate descriptive statistics
- Compare two experimental conditions
- Identify unusually slow observations
- Visualize reaction-time distributions

## Data

The dataset consists of **simulated reaction-time observations**, measured in milliseconds, for two hypothetical conditions.

No human participant data are used.

## Analysis

The MATLAB script calculates:

- Mean reaction time
- Median reaction time
- Standard deviation
- Mean difference between conditions
- Observations exceeding a simple mean + 2 SD threshold

A boxplot is also generated to visualize the distributions.

## Skills Demonstrated

- MATLAB syntax
- Numerical arrays
- Descriptive statistics
- Conditional data selection
- Basic data interpretation
- Data visualization

## Limitations

This is an educational demonstration using simulated data. It is **not an empirical cognitive experiment** and does not represent analysis of real participant data.

## File

`reaction_time_analysis.m` — MATLAB script containing the complete analysis.
