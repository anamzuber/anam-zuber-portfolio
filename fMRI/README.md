# Introductory fMRI

This section documents introductory learning in functional magnetic resonance imaging (fMRI) and its application to cognitive neuroscience.

## Concepts Covered

- BOLD (blood-oxygen-level-dependent) signal
- Hemodynamic response
- Experimental design and task paradigms
- Design matrices
- General Linear Model (GLM)
- Contrasts
- Statistical parametric maps
- Basic fMRI preprocessing concepts
- Interpretation of task-related activation

## Current Level

This is an introductory learning portfolio and does not represent independent fMRI research or analysis of real participant neuroimaging data.

The goal is to develop foundational neuroimaging knowledge relevant to future work in cognitive neuropsychology and clinical neuroscience.
