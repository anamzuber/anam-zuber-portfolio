# fMRI GLM Simulation

## Overview

An introductory computational demonstration of the General Linear Model (GLM) framework used in task-based fMRI analysis.

The project uses simulated data to illustrate how an experimental task regressor can be modelled against a simulated BOLD time series.

## Concepts Demonstrated

- Experimental task design
- Hemodynamic response function (HRF)
- Task-regressor construction
- Design matrices
- General Linear Model (GLM)
- Beta estimation
- Basic model interpretation

## Data

No real participant neuroimaging data are used. The data are simulated for educational purposes.

## Scope

This project demonstrates conceptual understanding of an fMRI analysis framework and should not be interpreted as independent analysis of real neuroimaging data.
